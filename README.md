# Roshan Rozgaar – Local Services Marketplace

**Roshan Rozgaar** is a web-based local services marketplace designed to connect customers with skilled professionals in their nearby areas. The platform aims to make finding and contacting electricians, plumbers, carpenters, painters, and other service providers easier and more convenient.

## Project Overview

The website provides a simple interface where customers can explore service providers, view their profiles, and discover professionals based on their location.

Our main goal is to build a platform that promotes trust, accessibility, and convenience between customers and local skilled workers.

## Features Implemented

- **Homepage:** Responsive landing page with navigation, search functionality, and service provider listings.
- **Worker Profiles:** Displays professional information, skills, experience, and service details.
- **Interactive Map:** Uses Leaflet and OpenStreetMap to display worker locations and calculate distances from the user's current location.
- **User Registration:** Signup interface integrated with Supabase Authentication.
- **Email Verification:** Supabase email confirmation functionality.
- **Database:** Supabase database with tables for user profiles, worker profiles, worker locations, bookings, and reviews.
- **User Interface:** Interactive elements, profile modals, notifications, and responsive layouts.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Supabase (Authentication and PostgreSQL Database)
- Leaflet.js
- OpenStreetMap
- Git and GitHub

## Incomplete Features and Limitations

The following features are not fully implemented yet:

- **Real Face Recognition:** The face scanning interface is currently a demonstration only. Actual biometric recognition and authentication have not been implemented.
- **Complete Login System:** The login functionality and full authentication flow still require completion and testing.
- **Live Worker Data:** Current worker listings and map locations use sample data rather than verified, real-time service provider information.
- **Complete Booking System:** The booking interface is not yet fully connected to the database.
- **Reviews and Ratings:** The database structure exists, but the complete review and rating functionality is not implemented.
- **Worker Dashboard:** A complete dashboard for service providers to manage their profiles, availability, and bookings is still pending.

## Future Improvements

In future development, we aim to implement real-time worker data, complete authentication, functional booking management, customer reviews, worker dashboards, and genuine face recognition.
